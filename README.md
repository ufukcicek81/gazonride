# GazonRide 🏍️

Motosiklet sürücüleri için sürüş takip uygulaması.

## V2
- Gerçek GPS konum takibi
- Sürüş başlat / bitir
- Anlık hız
- GPS mesafesi
- Rakım ve toplam tırmanış
- Ortalama / maksimum hız
- Sürüş süresi
- Mobil-first arayüz
- Son sürüşü cihazda saklama
- Sürüş paylaşımı

## Yol haritası
1. Gerçek harita ve rota çizimi
2. 3D/uydu rota animasyonu
3. Firebase kullanıcı ve sürüş geçmişi
4. Grup sürüşü / canlı konum
5. Hava durumu ve yakıt maliyeti
6. Sosyal paylaşım kartları
